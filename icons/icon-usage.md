## Icon Sources

## Iconography

**Use for:** UI elements, navigation, feature callouts, presentations

| Property | Value                                                              |
| -------- | ------------------------------------------------------------------ |
| Style    | Solid, not outlined                                                |
| Color    | Brand color on white background or white on brand color background |
